# ☕ Coffee Shop Sales Data Analysis

## 📌 Project Overview

This is a **mini data analysis project** based on a coffee shop sales dataset. The main purpose of this project is to explore and analyze coffee shop transaction data using Python and identify useful business insights from customer orders, coffee types, payment methods, and revenue.

The project demonstrates the basic data analysis workflow, including **data loading, data exploration, data cleaning, data transformation, aggregation, and data visualization**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze the coffee shop sales data.
* Identify the most popular coffee products.
* Calculate the total revenue generated by each coffee.
* Analyze customer payment methods.
* Identify sales patterns over time.
* Categorize transactions based on their monetary value.
* Create visualizations to understand the data more easily.

---

## 📊 Dataset

The dataset contains coffee shop transaction records with information such as:

| Column           | Description                          |
| ---------------- | ------------------------------------ |
| `date`           | Date of the transaction              |
| `datetime`       | Date and time of the transaction     |
| `cash_type`      | Payment method used                  |
| `card`           | Card/payment information             |
| `money`          | Transaction amount                   |
| `coffee_name`    | Name of the coffee purchased         |
| `money_category` | Category based on transaction amount |

The dataset contains approximately **3,600+ transaction records**.

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

### 1. Dataset Exploration

Used Pandas functions to understand the dataset:

```python
data.head()
data.info()
data.describe()
```

### 2. Missing Value Analysis

Checked for missing values using:

```python
data.isnull().sum()
```

Missing values were investigated and handled according to the dataset requirements.

### 3. Duplicate Removal

Duplicate records were identified and removed using:

```python
data = data.drop_duplicates()
```

### 4. Feature Creation

A new `money_category` column was created using the `apply()` function to classify transactions as **High** or **Low** based on the transaction amount.

---

## 📈 Data Analysis & Visualization

### ☕ 1. Most Popular Coffee

The number of orders for each coffee was calculated using:

```python
data["coffee_name"].value_counts()
```

A bar chart was created to identify which coffee products were ordered most frequently.

**Question answered:**

> Which coffee is the most popular based on the number of orders?

---

### 💰 2. Revenue Generated by Each Coffee

Total revenue for each coffee was calculated using:

```python
revenue = data.groupby("coffee_name")["money"].sum()
```

The results were visualized using a bar chart.

**Question answered:**

> How much total revenue did each coffee generate?

This analysis is useful because the most popular coffee is not necessarily the coffee generating the highest revenue.

---

### 💳 3. Payment Method Analysis

The `cash_type` column can be analyzed to understand customer payment preferences.

For example:

```python
data["cash_type"].value_counts()
```

This helps identify which payment methods are used most frequently.

---

### 📅 4. Sales Trend Analysis

The `datetime` column can be transformed to analyze sales patterns by:

* Month
* Day
* Weekday
* Hour

This can help answer questions such as:

> Which time of the day generates the most revenue?

and

> Which months have higher sales?
